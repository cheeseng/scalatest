PATTERN ESTABLISHED
-------------------
For opaque numeric types (like PosZInt, PosZLong), the implementation includes:
1. Factory methods: apply (compile-time), from, ensuringValid, tryingValid, passOrElse, goodOrElse, rightOrElse, fromOrElse
2. Validation: isValid
3. Constants: MaxValue, MinValue
4. Extension methods: value, abs, max, min, string conversions (toBinaryString, toHexString, toOctalString), ranges (to, until), transformations (ensuringValid)
5. Conversions: to underlying type (unwrap), from integer literals
6. Ordering instance
